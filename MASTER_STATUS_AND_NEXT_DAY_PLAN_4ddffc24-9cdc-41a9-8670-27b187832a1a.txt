REASON 2: GTKWAVE DEFAULT EMPTY WINDOW (BLACK SCREEN)
------------------------------------------------------
GTKWave is a raw digital logic analyzer. When it opens a fresh .vcd waveform file
for the very first time, it opens with a blank black grid until you click the
left-hand tree and drag signals (clk, v_mem, spike_out) into the trace list.
To someone unfamiliar with GTKWave, it looks like "nothing is there / no graphs".
RESOLUTION:
1. We created "hardware/neuroquant_lif.gtkw" which pre-configures and auto-loads
   all signals so GTKWave opens with active traces immediately.
2. Even better: We built an automated Python chart renderer:
   "hardware/render_hardware_waveform.py"

   "hardware/lif_neuron_waveform.png"
